# 版式与动画

先读懂文案，再决定画什么、放哪、什么时候出。下面每条都写了原因和来源，用来判断，不是照抄的数字。

## 一段画面怎么想

1. **一句话目标**：观众看完这段要记住什么（一个结论、一组对比、一个因果）。
2. **找视觉比喻**：把抽象词变成能动的东西。“算力”是机器、“同质化”是一排一样的塑料盒、“效率陷阱”是地上裂开的坑、“判断力”是一把尺子/一只验收章。文章原配图只帮你理解意思，不要把配图直接动起来；找更巧妙的演法。
3. **排站位**：在纸上画出关键几帧（每个 cue 一帧），确认从左往右读得通、运动路径不交叉、不压字幕和口播窗。
4. **排时间**：每个 cue 时刻发生一件事；两件事之间至少隔 ~10 帧，让观众看清。
5. **只留一个重点**：实蓝和最大的字给这一段最重要的那个词。

## 版面

- **口播图解（aroll）**：真人窗在侧边约 1/3，另一侧放标题和图解。图解区用 `G.art.withPresenter`。标题横版约 96px、竖版约 72px，两行以内；左上放栏目贴纸（plan 的 `tag`）。
- **芽仔演示（broll）**：真人退场，用整窗 `G.art.full`。需要户外场景时用 `Scenery`（天空、远山、云、地平线）；不需要就留白纸。
- **一屏元素按口播替换**：新的进来，旧的退场或缩到角落成为“已讲过”。不往上堆。一次反例中，一屏堆了约 10 个元素，没有重点，被打回。
- **留白**：字与字、元素与元素之间留足距离；靠太近会叠，看着乱。
- **字幕区**：`G.caption.top` 以下只放字幕。

## 动画的“抓眼”从哪来

参考片（Winhao《六步学会 Opus5.5 做动画视频》）的好，在于 IP 是图解里的演员：Clawd 坐小火车载着分镜卡跑、在节拍格子之间跳着点亮、沿时间轴滑到某一秒、举牌、按卡片。照这个思路：

- **芽仔推动图解**：芽仔把卡片推进格子、扔纸团进机器、踩亮按钮、从坑里跳出来、拉开幕布揭晓答案。动作完成的那一刻 = cue。
- **镜头动起来**：一段里用 `Camera` 推近一次到重点，或从全景平移到细节；一两次就够，多了晕。
- **转折有力度**：结论用 `Stamp` 盖章、数字用 `CountUp`、关键词用 `TornBlue` 撕出来、`Highlight` 刷荧光。
- **物理感**：落地有回弹（`usePop`）、砸下有震动、飞出有抛物线，比淡入淡出生动。
- **声音点睛**：出现配 `pop`，落地配 `thud`，揭晓配 `ding`，划过配 `swish`；一秒内不超过两个。
- **段间转场**：类型切换时总装已经加了淡蓝撕纸扫过；同类相接直接切，靠画面里的元素接戏（例如芽仔从 s02 的坑里跳进 s03）。

## 芽仔表演

- 表情只卡情绪关键词：`star` 得意、`surprise` 惊讶、`awkward` 尴尬、`doubt` 疑惑、`love` 喜欢、`happy` 开心、`loading` 思考中。用 `useFace([[帧,'表情',持续帧]],[眨眼帧])`，其余时间普通脸。
- 不做待机小跳；`useHop` 只在“兴奋”“秒出”这类词上跳两下。
- 头可以轻歪（`headRot` ±6°）表示犹豫；`sprout` 叶子轻摆让它活着。
- 进场退场要有交代（跳进、走出、掉下去），不要凭空消失。

## 每段的底线

下面几条是“这段算做了”的最低标准，用来在交付前自查，也用来验收别人写的场景。

- **每个 cue 画面都变一次**：新东西进来、旧东西退场、芽仔做完一个动作，三者至少占一样。只换一行字不算。
- **芽仔的动作有因有果**：推了，东西要动；跳了，要落在某个地方；被砸了，要有反应。只从左平移到右、或只在原地换表情，等于站桩。
- **道具是这段文案专属的**：这段讲“声波”就画声波，讲“便签”就画便签。全片反复只用同一种卡片，观众分不出段和段。
- **段文件自己读得懂**：开头注释写了每个 cue 发生什么；正常一段 30–70 行。只有两三行的段，是在套模板。

## 反例（都发生过）

| 现象 | 原因 | 改法 |
|---|---|---|
| “你本人”在说到之前就挂在画面上 | 元素没跟口播 | 放到对应 cue 再出 |
| 芽仔面罩一直换表情、一直小跳 | 表情没卡关键词 | 只在情绪词亮，亮完停住 |
| 所有内容压在地平线上，线下空一条 | 机械沿用 B 段地面 | 口播段去掉地面，站位下移 |
| 机器穿过芽仔 | 运动路径交叉 | 预先排站位，改方向 |
| 口播小窗缩在角落，压住顶栏和栏目贴纸 | 芽仔段还留着真人 | 芽仔段真人退场 |
| 白纸上的米色胶带显脏 | 贴纸色不对 | 用淡蓝不透明贴纸 |
| 说“学了参考片”但画面没变化 | 没落到具体改动 | 交付时逐条写学了什么、改在哪 |
| 每段都是“大字 + 卡片 + 芽仔平移过去”，动画僵 | 33 段套同一个通用模板，每段只填词 | 一段一段写，每段按文案画专属道具和动作 |
| 芽仔少了一条胳膊 | 给描线手臂加了旋转，轴心是猜的 | 不改芽仔身体；用前倾、位移和道具位置演 |
| 配音含糊，两段话连成一句 | 稿子段尾没标点，拼句时上下段粘在一起 | `script.txt` 用空行分段（脚本会补气口） |
